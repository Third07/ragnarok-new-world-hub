How to use the Ragnarok: The New World Affix Planner

Choose your class and next job, set the target level range, then filter affixes by rarity and skill level. Pick an equipment slot before assigning an affix; the loadout keeps each named affix unique so the same effect cannot be equipped twice. Use the result alongside your skill and rune choices to compare a complete RTNW build before committing resources in game.
